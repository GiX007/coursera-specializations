# Coursera Specializations

This repository contains my completed programming assignments and guided projects from various [Coursera](https://www.coursera.org/) specializations.  
Much of my journey started with **Andrew Ng’s courses**, which got me interested in machine learning and deep learning. Since then, I’ve continued learning through [DeepLearning.AI](https://www.deeplearning.ai/) and other programs, covering **machine learning, deep learning, NLP, TensorFlow, and data science**.
